## How Layers Work

Your keyboard has multiple layers. You switch between them by **holding the thumb keys**:

- **Left thumb, bottom row**: Hold to activate layers
- **Right thumb, bottom row**: Hold to activate layers
- **Tap** the same key for its primary function (e.g., `SPACE`, `ENTER`, `ESCAPE`)
- **Hold** the key to activate the layer it's assigned to

**Quick activation map:**
- Hold left `ESC` → **MEDIA layer** (most important for quick access)
- Hold other thumb combinations → access other layers
- You can also hold layer keys while holding modifiers (Shift, Ctrl, Alt, Cmd)

## BASE Layer

![my_keymap](../../keymap_img/keymap_base.svg)

Your main typing layer. Uses **Colemak-MOD DH** layout for efficient typing.

| Key Group | Keys |
|-----------|------|
| **Letters** | Q W F P B / J L U Y (Colemak layout) |
| **Special Chars** | ` (backtick), ~ (tilde), ´ (acute), Ç, " (quote), ' (apostrophe) |
| **Modifiers** | Hold A, R, S, T for Ctrl, Alt, Shift, GUI (left side) |
| **Thumb Keys** | `SPACE` (tap) / Layer (hold), `TAB` (tap), `ESC` (tap / MEDIA hold) |
| **Right Thumb** | `ENTER` (tap), `BACKSPACE` (tap), `DEL` (tap) |

## NAV Layer (Navigation & Editing)

![my_keymap](../../keymap_img/keymap_nav.svg)

Activated by holding the left thumb key. Use this for cursor movement and editing without leaving the home row.

| Position | Function |
|----------|----------|
| **Home row (ASDF area)** | ← (Left), ↓ (Down), → (Right), plus modifiers |
| **Above home row** | Page Up, Page Down, Home, End |
| **Bottom row** | Duplicated base layer keys for easy editing flow |
| **Number keys** | Quick number access while navigating |

**Use case:** Select text or move around your document while keeping your hands in position.

## NUM Layer (Numbers)

![my_keymap](../../keymap_img/keymap_num.svg)

Activated by holding the right thumb key. Provides number pad layout with editing helpers.

| Position | Keys |
|----------|------|
| **Top row** | 7, 8, 9 |
| **Middle row** | 4, 5, 6 |
| **Bottom row** | 1, 2, 3 |
| **Right thumb** | 0 (zero) |
| **Extra** | . (dot) for decimals |

**Modifiers available:** Shift, Alt, Ctrl on left side for quick key combinations while typing numbers.

## SYMBOLS Layer (Shifted Symbols)

![my_keymap](../../keymap_img/keymap_sym.svg)

Access common programming and writing symbols without chording Shift.

| Symbol | Use |
|--------|-----|
| `!`, `@`, `#`, `$`, `%` | Common symbols (top row) |
| `-`, `=`, `[`, `]`, `\` | Math and code brackets |
| `_`, `+`, `{`, `}`, `\|` | More code symbols |
| `(`, `)` | Parentheses |
| `^`, `&`, `*` | Math operators |

**Pro tip:** These are already "shifted" versions, so you don't need to hold Shift while typing.

## MOUSE Layer

![my_keymap](../../keymap_img/keymap_mouse.svg)

Control your mouse without touching the trackpad. Hover over keys to see mouse functions.

| Position | Function |
|----------|----------|
| **Home row** | Mouse movement: ← ↓ ↑ → |
| **Below home row** | Scroll: Left, Down, Up, Right |
| **Right thumb** | Left click, Middle click, Right click |
| **With modifiers** | Hold Shift/Ctrl/Alt for faster/slower movement |

**Use case:** Fine-grained mouse control for precise clicking or when trackpad isn't available.

## WM Layer (Window Management)

![my_keymap](../../keymap_img/keymap_wm.svg)

Quick access to window management shortcuts (designed for macOS with Command key).

| Key | Function |
|-----|----------|
| **Corners (top row)** | Snap windows to screen corners |
| **Sides (middle row)** | Snap windows to screen halves |
| **Center (bottom row)** | Center window |
| **Hold Shift** | Alternative window positions |

**Note:** Shortcuts use `Cmd+Number` combinations common in window management apps.

## MEDIA Layer (Media & Bluetooth)

![my_keymap](../../keymap_img/keymap_med.svg)

Control media playback and Bluetooth connections. Activated by **holding left `ESC`**.

| Position | Function |
|----------|----------|
| **Top row** | Brightness Down, Brightness Up |
| **Middle row** | Play/Pause, Previous, Volume Down, Volume Up, Next |
| **Bottom row** | Bluetooth: BT 0, BT 1, BT 2, BT 3, BT 4 |
| **Extra** | BT Clear (bottom left), Mute |

**How to switch Bluetooth profiles:**
1. Hold left `ESC` to activate MEDIA layer
2. Tap one of the BT buttons (0-4) to connect to that profile
3. Hold Shift + BT button to clear that profile

## FUNC Layer (Function Keys)

![my_keymap](../../keymap_img/keymap_func.svg)

Access F1-F12 function keys and shifted versions for application shortcuts.

| Position | Function |
|----------|----------|
| **Top row** | F7, F8, F9, F10 |
| **Middle row** | F4, F5, F6, F11 |
| **Bottom row** | F1, F2, F3, F12 |
| **Hold Shift** | Shifted versions: Shift+F1, Shift+F2, etc. |

**Use case:** Application shortcuts, system functions (Volume, Brightness if not in MEDIA layer), or gaming macros.

## Getting Started

1. **Start with BASE layer** - Practice the Colemak layout
2. **Learn NUM layer** - Add number input to your workflow
3. **Explore NAV layer** - Once comfortable with navigation, speed increases dramatically
4. **Add MEDIA layer** - For laptop power users (Brightness, Volume, Bluetooth)
5. **Master the rest** - Add SYMBOLS, MOUSE, WM, and FUNC as needed

**Tips:**
- All layers preserve the base layer's modifier keys (Shift, Ctrl, Alt, Cmd)
- Thumb keys can be held while using other keys for fast layer switching
- Practice one layer at a time to build muscle memory
